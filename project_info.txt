============================================================
       PHISHING URL DETECTOR — PROJECT OVERVIEW
============================================================

------------------------------------------------------------
LIBRARIES / TOOLS USED
------------------------------------------------------------

1. STREAMLIT (>= 1.30.0)
   - What: Turns Python code into a web app
   - How Used: Builds the entire UI — input box, buttons,
               result cards, progress bar, feature table

2. SCIKIT-LEARN (>= 1.3.0)
   - What: Machine Learning library
   - How Used: Trains & runs the ML model (Random Forest)
               that predicts if a URL is phishing or safe

3. PANDAS (>= 2.0.0)
   - What: Data handling / table library
   - How Used: Organizes URL features into a table (DataFrame)
               that the ML model can read and process

4. NUMPY (>= 1.24.0)
   - What: Math and numbers library
   - How Used: Helps with numerical calculations behind the scenes

5. JOBLIB (>= 1.3.0)
   - What: Save and load Python objects to disk
   - How Used: Saves the trained model so it doesn't retrain
               every time the app starts

6. MATPLOTLIB (>= 3.7.0)
   - What: Chart and graph library
   - How Used: Used for visualizing training results in the
               Colab notebook (accuracy, feature importance)

------------------------------------------------------------
KEY FILES & WHAT THEY DO
------------------------------------------------------------

app.py
   - The main app file
   - Shows the web UI where you type a URL and get a result
   - Loads the model, extracts features, and shows verdict

feature_extractor.py
   - Breaks a URL into 20 clues/features
   - Examples: Is it HTTPS? Does it have @? Is it too long?
               Does it contain suspicious words? Brand spoofing?

train_model.py
   - Trains the ML model on the dataset
   - Saves the trained model to phishing_model.joblib

phishing_model.joblib
   - The saved, ready-to-use trained ML model
   - Loaded by app.py every time the app runs

model_metadata.joblib
   - Stores extra info about the model (accuracy, feature names)
   - Displayed in the app for transparency

phishing_url_dataset.csv
   - Training data — thousands of real phishing & safe URLs
   - Used by train_model.py to teach the ML model

sample_urls.txt
   - A collection of test URLs (phishing + safe) to try in the app

generate_outputs.py
   - Generates charts and evaluation reports for the model

Phishing_URL_Detector_Colab.ipynb
   - Google Colab notebook version of the full project
   - Used for training and experimenting in the cloud

requirements.txt
   - Lists all Python libraries needed to run the project

------------------------------------------------------------
HOW IT ALL WORKS (SIMPLE FLOW)
------------------------------------------------------------

  You type a URL
        |
        v
  feature_extractor.py
  -> Pulls 20 clues from the URL
        |
        v
  phishing_model.joblib
  -> ML model checks those 20 clues
        |
        v
  app.py (Streamlit UI)
  -> Shows "SAFE" or "PHISHING" with risk score

------------------------------------------------------------
THE 20 CLUES THE MODEL CHECKS
------------------------------------------------------------

 1. url_length              - Total length of the URL
 2. hostname_length         - Length of the domain name
 3. path_length             - Length of the path after domain
 4. num_dots                - Number of dots (.) in the URL
 5. num_hyphens             - Number of hyphens (-) in the URL
 6. num_underscores         - Number of underscores (_) in URL
 7. num_digits              - Count of numbers in the URL
 8. num_special_chars       - Non-alphanumeric character count
 9. num_subdomains          - Number of subdomains
10. url_depth               - How deep the URL path goes
11. num_query_params        - Number of ?param=value parts
12. has_at_symbol           - Does URL contain @ symbol?
13. has_https               - Is it HTTPS (secure)?
14. has_ip_address          - Is the host a raw IP like 1.2.3.4?
15. has_shortener           - Is it a shortener like bit.ly?
16. num_suspicious_keywords - Words like "login", "verify", "password"
17. has_brand_in_subdomain  - Brand name (google, paypal) in wrong place?
18. digit_ratio             - What % of URL is numbers?
19. url_entropy             - How random/scrambled does the URL look?
20. tld                     - Top-level domain (.com, .net, .xyz, etc.)

------------------------------------------------------------
SUSPICIOUS KEYWORDS DETECTED
------------------------------------------------------------
login, signin, verify, update, banking, secure, account,
confirm, password, suspend, alert, support, validate,
unlock, billing, webscr

------------------------------------------------------------

------------------------------------------------------------

wellsfargo, fedex, binance, icici, hdfc, bankofamerica, whatsapp

------------------------------------------------------------
HOW TO RUN THE APP
------------------------------------------------------------

  Step 1: Install dependencies
          pip install -r requirements.txt

  Step 2: Run the app
          streamlit run app.py

  Step 3: Open browser at http://localhost:8501
          Type any URL and click "Analyse URL"
